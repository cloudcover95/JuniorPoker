# What is original here

Not a casino floor clone. Not Shuffle Master. Not Walker Digital table-intel.

## Original (this tree)

1. **Cloud-bubble gate** — hole faces stay `**` until that seat `rub`s. Other seats stay blind. Software privacy, not a surveillance matrix.
2. **Tap → rub, not locate** — `Reader.tap(tag, seat)` is an event. No sequenced antenna array, no bet-spot inference, `live=False` until the owner plugs a reader.
3. **Trit pack is not the pot** — Winsor I2_S hex is a neighbor key for Home/OSai. Combo-21 + ABC agree-check ranks the hand.
4. **T-layer wash** — C Fisher–Yates on the Pi (`jp_shuffle`), Python fallback. Canonical randomness is software, not a patented shoe.
5. **Loopback party/peer** — seats join *our* `table_id`. No official-room injector (`casino_client: false`, `inject: false`).
6. **Home suite** — Flagstaff vote, lab spool `fire: false`, OSai goldens `poker-abc` / `poker-store`. Same note protocol as Gaia, not DDS multicast.

## Commodity (on purpose)

- 52-card encoding, Hold'em deal + burns
- Boxed 13.56 MHz decks (ICODE / NTAG) as a *buy* option
- Arcade buttons + KY-040 as HID
- OpenSCAD trough geometry
- C(7,5)=21 evaluator class (not TwoPlusTwo LUT)

## Deliberately not built

Sequenced seat/board coils that triangulate every tag. Chip accounting. Optical shoe. Motor wash that copies SHFL claims. DOM clickers.

See `docs/PATENTS.md` before productizing RFID hardware.
