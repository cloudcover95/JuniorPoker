# Online from a seat

Felt play stays RFID + rub.

From the same chairs you can:
- **felt** — cards on this rail only
- **party** — every occupied seat shares one JuniorPoker `table_id` (home game over loopback/VPN you run)
- **solo** — one seat leaves the party and sits a different `table_id`
- **peer** — another box running this same spec

Not shipped: PokerStars/GG/WSOP apps, screen-scrape, bot seats, credential vaults.
A commercial site is an *operator adapter* they publish; we do not impersonate one.
